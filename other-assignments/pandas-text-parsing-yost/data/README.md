# Data dictionary

Three CSV files. `events.csv` joins to `games.csv` on `game_id`, and to
`roster.csv` on `jersey` (for Michigan players only). **Everything here is
simulated** — see the note at the bottom before you quote any of it.

## `events.csv` — 4,065 rows, one per event

| column | type | notes |
|---|---|---|
| `event_id` | string | `E00001`, unique, chronological |
| `game_id` | string | joins to `games.game_id` |
| `period` | int | `1`, `2`, `3`, or **`4` for overtime** |
| `description` | string | the entire event, as one line of text |

Every description opens with the same five fields, separated by whitespace:

```
TYPE  CLOCK  TEAM  #JERSEY  PLAYER
```

`TYPE` is `GOAL` (256), `SHOT` (2,114), `HIT` (687), `BLOCK` (480), `PENALTY`
(360) or `TAKEAWAY` (168). `CLOCK` is **time remaining in the period**. `TEAM`
is `MICH` or one of sixteen opponent codes. `PLAYER` is an initial and a
surname.

Two types carry more after that:

```
GOAL     ... (A: #9 R. Karr, #22 D. Ochoa) [EV]
GOAL     ... (unassisted) [PP]
PENALTY  ... (Tripping, 2 min)
```

Strength tags: `EV`, `PP`, `SH`, `EN`, `PS`.

### Deliberate messiness

The awkward parts are the assignment:

- **487 descriptions carry stray leading or trailing whitespace**, and **231
  have a doubled space** in the middle. A pattern anchored with `^` and written
  with literal spaces silently drops those rows and produces `NaN` instead of
  an error. That is Question 2, and it is the single most common way a scraper
  pipeline reports the wrong number to somebody.
- **665 clocks have no leading zero** (`8:45`, not `08:45`), so `\d{2}:\d{2}`
  is not enough.
- **The clock counts down.** `19:16` in the first period is 44 seconds into the
  game. Question 3 turns that into one honest number, and **overtime is 300
  seconds long, not 1,200** — the difference is worth 3 points on its own.
- **35 goals are unassisted**, and the rest name one or two players. A single
  `.str.extract` finds only the first assist; Question 4 needs
  `.str.findall` and `.explode`.
- **Infractions have spaces and hyphens in them** — `Delay of Game`,
  `Cross-checking`, `Contact to the Head`. A one-word pattern gets three of the
  thirteen right (Question 5).
- **Surnames contain a period, an apostrophe and a hyphen** — `R. St. Pierre`,
  `L. O'Halloran`, `P. Vander-Meer`. "The second word" is the wrong rule
  (Question 6).
- **Opponent jersey numbers collide with Michigan's.** Nothing in a
  description says which roster a number belongs to except the `TEAM` field, so
  a count that skips it is wrong in a way that still looks plausible.

## `games.csv` — 41 rows, one per game

| column | type | notes |
|---|---|---|
| `game_id` | string | join key |
| `season`, `game_no` | int | one season, games 1–41 |
| `date` | date | 2023-10-04 through 2024-03-07 |
| `opponent` | string | sixteen teams |
| `opponent_code` | string | the code that appears in the feed |
| `site` | string | `Home` (20), `Away` (18), `Neutral` (3) |
| `venue` | string | `Yost Ice Arena` for home games |
| `michigan_goals` | int | 143 total; **five games at 0** |
| `opponent_goals` | int | 113 total |
| `result` | string | `W` (23) or `L` (18) |
| `overtime` | int | `1` for the 6 games that went past regulation |
| `attendance` | int | |

**The five shutouts are the point of Question 9.** A `groupby(...).min()` over
Michigan goals simply has no row for them, and the honest way to put them back
is `NaN`, not `0`.

## Provenance

Generated by `../tools/generate_data.py` with seed **1996** (the year Michigan
won its ninth NCAA hockey championship). The generator is deterministic — rerun
it and you get byte-identical files.

Real: Yost Ice Arena, the opponents and their arenas, and the format of a
college hockey play-by-play feed.

Simulated: every player, every name, every event, every score. **Do not cite
any of it as a real statistic.**
