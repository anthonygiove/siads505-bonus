# Data dictionary

Two CSV files, joined on `opponent`. **Both are simulated** — see the note at
the bottom before you quote any of it.

## `games.csv` — 195 rows, one per game

| column | type | notes |
|---|---|---|
| `game_id` | string | unique, `<season>-W<week>`, e.g. `2016-W07` |
| `season` | int | 2010–2024, thirteen games per season |
| `week` | int | 1–13 |
| `date` | date | `YYYY-MM-DD`, always a Saturday |
| `kickoff` | string | 12-hour local time, e.g. `3:30 PM` |
| `opponent` | string | joins to `opponents.opponent` |
| `site` | string | `Home` (103), `Away` (77), `Neutral` (15) |
| `stadium` | string | `Michigan Stadium` for home games |
| `michigan_points` | int | no ties anywhere in the dataset |
| `opponent_points` | int | |
| `attendance` | float | **13 missing** |
| `temperature_f` | float | at kickoff; **7 missing** |
| `weather` | string | `Sunny`, `Cloudy`, `Overcast`, `Rain`, `Snow`, `Windy` |
| `student_tickets_sold` | float | home games only, so **92 are blank by design** |
| `avg_ticket_price` | string | messy on purpose: `$` prefix, 8 rows with stray whitespace, 5 rows reading `unavailable` |
| `head_coach` | string | the real coaching timeline |

### Deliberate messiness

The gaps and the dirty price column are not mistakes. They are the assignment:

- `attendance` gaps force a group-aware fill (Question 7). A single global
  median would invent ~40,000 fans in Ann Arbor and lose them on the road.
- `student_tickets_sold` is blank for every away and neutral game — a missing
  value that means "not applicable", not "we lost the number".
- `avg_ticket_price` needs `.str` cleaning plus a coercion to `NaN`
  (Question 4). `unavailable` was chosen because `read_csv` does *not* treat it
  as a missing value, so it survives the round trip to disk and the student has
  to deal with it.
- `pivot_table` on weather × site leaves one genuinely empty cell — there are
  no neutral-site snow games (Question 10).

## `opponents.csv` — 32 rows, one per team

| column | type | notes |
|---|---|---|
| `opponent` | string | join key |
| `conference` | string | `Big Ten`, `SEC`, `MAC`, `Pac-12`, `ACC`, `Mountain West`, `Sun Belt`, `Independent` |
| `mascot` | string | |
| `home_state` | string | two-letter code |
| `home_stadium` | string | |
| `stadium_capacity` | int | |
| `founded` | int | year the school was founded |
| `is_rival` | bool | `True` for Ohio State, Michigan State and Notre Dame |

**Only 30 of these 32 teams appear in `games.csv`.** Boston College and Oregon
are listed but never played. That is on purpose: a `how="inner"` or
`how="right"` merge quietly changes the row count, and Question 8 checks that
the student's join still returns exactly 195 games.

## Provenance

Generated by `../tools/generate_data.py` with seed **1817** (the year the
University of Michigan was founded). The generator is deterministic — rerun it
and you get byte-identical files.

Real: team names, conferences, mascots, home states, stadium names and
capacities, founding years, and Michigan's head coaches by season.

Simulated: every score, attendance figure, temperature, weather condition and
ticket price. **Do not cite any of it as a real statistic.**
