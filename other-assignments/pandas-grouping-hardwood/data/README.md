# Data dictionary

Three CSV files. `box_scores.csv` joins to `games.csv` on `game_id`, and to
`roster.csv` on **both** `season` and `player_id`. **Everything here is
simulated** — see the note at the bottom before you quote any of it.

### Deliberate messiness

The awkward parts are the assignment:

- **1,134 rows are `DNP`.** The player dressed and never checked in. On those
  rows `minutes` reads `"DNP"` and every statistical column is blank, which is
  why the counting stats read back as `float` rather than `int`. A DNP is not
  a zero: the player did not go 0-for-0, he did not shoot. Questions 2, 3 and 5
  all turn on getting that distinction right.
- **Shooting lines are strings.** `"7-13"` is two numbers in a trench coat.
  Splitting it is Question 2, and the split has to leave the DNP rows as `NaN`.
- **Playing time is `MM:SS`.** Reading only the part before the colon quietly
  discards about eight percent of every player's season. Question 3 checks the
  rows where the clock did not land on a round minute.
- **Zero attempts are everywhere.** In 477 games a player checked in and
  never attempted a three; in 704 he never attempted a free throw.
  `fg3_made / fg3_att` is `NaN` on those rows, not `0.0` and not `inf` — that
  is Question 4.

## `roster.csv` — 150 rows, one per player per season

| column | type | notes |
|---|---|---|
| `season` | int | part of the join key |
| `player_id` | string | the other part of the join key |
| `player`, `jersey`, `hometown` | | |
| `position` | string | `G`, `F`, `C` |
| `class` | string | `Fr`, `So`, `Jr`, `Sr` |
| `height_in` | int | inches |
| `dressed` | bool | `True` for the 13 who suit up, `False` for the 2 who do not |

**Join on `season` *and* `player_id`.** A `player_id` appears in as many as
four seasons and is in a different `class` in each of them, so merging on
`player_id` alone multiplies the rows instead of labelling them — 4,160 box
score lines become 12,000-odd. Question 10 depends on getting this right.

**Nine of the 57 players never appear in a box score.** They are the redshirts
(`dressed == False`) who stayed on the roster all four years. A `how="right"`
or `how="outer"` merge invents rows for them.

## Provenance

Generated by `../tools/generate_data.py` with seed **1989** (the year Michigan
won the men's basketball national championship). The generator is
deterministic — rerun it and you get byte-identical files.

Real: the arenas, the conferences, and the shape of a Big Ten schedule.

Simulated: every player, every name, every box-score line, every final score,
every attendance figure. **Do not cite any of it as a real statistic.**
